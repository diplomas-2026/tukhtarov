# Разработка подсистемы управления статусами заказов для ООО «ПК Импульс»

Проект состоит из двух частей:

- `tukhtarov-api` - Spring Boot API с PostgreSQL, сущностями заказов, пользователей, клиентов, статусов и комментариев
- `web` - React + Material UI интерфейс для работы с заказами по ролям

## Запуск

1. Поднимите PostgreSQL и настройте параметры подключения в `tukhtarov-api/src/main/resources/application.properties` или через переменные окружения.
2. Запустите backend.
3. Запустите frontend.

## Автозагрузка тестовых данных

При старте API система проверяет таблицу `app_users`.

- Если таблица пользователей не пуста, seed не выполняется.
- Если таблица пользователей пуста, API очищает demo-таблицы и загружает полноценный набор тестовых данных в PostgreSQL.

Тестовый набор включает:

- пользователей для всех ролей;
- клиентов;
- несколько заказов;
- историю статусов;
- комментарии;
- разные статусы и приоритеты, чтобы можно было показать весь функционал системы.

## Тестовые пользователи

| Логин | Пароль | Роль | Назначение |
|---|---|---|---|
| `admin` | `admin123` | Администратор | Полный доступ, управление пользователями и клиентами |
| `manager` | `manager123` | Менеджер | Создание и сопровождение заказов |
| `executor` | `executor123` | Исполнитель | Работа по назначенным заказам |
| `client` | `client123` | Клиент | Просмотр своих заказов |

## Что умеет система

- авторизация по логину и паролю;
- просмотр заказов по роли;
- карточка заказа с деталями, комментариями и историей статусов;
- смена статусов;
- создание заказов;
- управление пользователями;
- управление клиентами;
- клиентский просмотр своих заказов.

## API

Базовый URL:

- `https://tukhtarov.danbel.ru/api/`

Основные endpoints:

- `POST /auth/login`
- `GET /auth/me`
- `GET /dashboard`
- `GET /orders`
- `GET /orders/{id}`
- `POST /orders`
- `PATCH /orders/{id}`
- `PATCH /orders/{id}/status`
- `POST /orders/{id}/comments`
- `GET /users/list`
- `POST /users`
- `PATCH /users/{id}`
- `GET /clients/list`
- `POST /clients`
- `PATCH /clients/{id}`
